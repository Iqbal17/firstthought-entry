# One Word, First Thought

Entry for the make.fun bounty "One Word, First Thought".

The program writes exactly ONE word — the first word that comes to
mind — to `entry.txt`. A judge model compares entries two at a time
and picks the more interesting word; surprise, vividness and a spark
of wit beat safe filler.

Our word: **defenestration** — the act of throwing someone out of
a window. Surprising, vivid, and funny: a formal Latinate word for
a chaotic, physical act.
